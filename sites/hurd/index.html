01 · What is the GNU Hurd

A kernel made of
cooperating strangers.

The GNU Hurd is a collection of user-space servers running on top of the GNU Mach microkernel. Instead of one privileged program doing everything, each capability of the OS — filesystems, networking, process bookkeeping, authentication — is its own small, replaceable program talking over message passing.

04 · Two ways to build an OS

Monolithic vs.
microkernel.

On the left, a monolithic kernel (Linux-style): filesystems, drivers, networking and process management are welded into one privileged binary. On the right, the Hurd's microkernel approach: GNU Mach provides only IPC, scheduling and memory, everything else is an ordinary user-space server.
